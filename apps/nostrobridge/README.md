# Nostrobridge demo

Next.js App Router UI for `@bchblaze/identity`.

```bash
# from the repo root
pnpm install
pnpm dev
```

Judge walkthrough, bounty mapping, and the “verify without trusting the site” command live in the [root README](../../README.md).

Throwaway dual-signed fixture: `public/sample-binding.json` (load it on `/verify`). Do not send BCH to that address.

Banner env vars: `.env.example` → `.env.local`.
